## Honest read (locked metrics)

- **Nipun** — clone WINS on: balanced move 14% (> majority 11%, cross 12%); fire recall on visible ticks 79% (majority 0%).
- **Nipun** — clone LOSES on: a baseline had smaller moved-position error (clone 3.42, best baseline 3.16).
  - Why, plainly: the training set is 1–2 matches, so for many situations the nearest neighbor is far and the breaker (fired 5% of the time) hands control to the basic bot — itself a baseline, so the two converge there. Position error is hard to beat because a mostly-still person is matched closely by "majority = stop". This is a data limit, not a metric trick; the factored votes and fire-visibility split are in place and should separate once a player has 3+ varied matches.
- **What-if:** best-plan win vs the clone median 100% vs the basic bot median 60%. The clone now fires 19% of visible ticks vs the bot's 85%. The clone still fires less than the bot, so treat clone win rates as a ceiling until more firing data arrives.
