## Honest read

- **Nipun**: own clone did NOT clearly beat the baselines — a baseline matched moves as well or better ("majority action" at 31% vs own 29%); a baseline landed closer in position.
  - Likely why: the dataset is tiny and human play is noisy. With one or two training games the KNN has few neighbors, so it often falls back through the breaker to the same hand-written moves the basic bot uses, and a human who mostly holds still is easy for the majority-action baseline to match. This is a data problem, not a code problem — the learning curve shows the direction, and more games should separate them.
- **What-if:** the plans win often (median 100%), but the clone fired on only 32% of the ticks it could see the human. So the win rate is partly the clone being too passive, not the plan being strong. The fix is more recorded human games where the person actually shoots, so the clone learns to shoot back; the circuit breaker's basic bot does shoot, which is why head-on the audit still passes.
